# Gesture Controlled 3D Particle System

Control 3D particles with hand gestures using your webcam.

## Gestures
- One finger: Saturn
- Peace sign: MEN ARE BRAVE
- Three fingers: I AM BATMAN
- Four fingers (thumb in): GOTHAM IS MINE
- Fist: Batman logo
- Both fists: I AM VENGEANCE

## Run
pip install -r requirements.txt
python batman.py
